# 鬼谷八荒修改器 (GhbgEditor)

一个可置顶的 Windows 悬浮窗修改器。提供两种修改方式：

1. **内存修改（实时生效，无需重启/导入存档）**：附加游戏进程，扫描内存数值并修改、锁定。
2. **存档修改（改完在游戏内导入存档）**：把加密 `.cache` 存档解成 JSON，按「查找 / 替换」规则批量修改后加密写回。

**仅支持单机模式**。当前适配游戏版本：**v1.2.106（PC / Steam 版）**。

## 界面

- **悬浮窗置顶**：默认置顶，可取消勾选，右上角可关闭。
- 两个标签页：`内存修改` / `存档修改`。

### 内存修改（实时，推荐日常用）

流程：

1. 打开游戏并进入存档（人物已在世界里走动）。
2. 切到修改器 `内存修改` 页 → 点【刷新】→ 选 `guigubahuang` 进程 →【附加进程】。
3. 记下游戏里当前数值（例如灵石 561），在【当前数值】填 `561`，数值类型默认 `int32`，点【首次扫描】。
4. 回游戏让数值变一次（花掉/赚到一点灵石）。
5. 回修改器点【增大了】或【减小了】（或填新值点【精确值】）。重复 2-3 次，地址会筛到 1~5 个。
6. 选中结果行 →【↓ 加入修改项】，写入值改成想要的数（如 `999999`）。「锁定」勾选后每 0.4 秒自动持续写入，数值不会掉。
7. 点【立即写入】，切回游戏即生效，不用重启、不用导入存档。

说明：内存地址每次启动游戏都会变，重新开游戏后重新扫描一次即可。查不到时把数值类型换成 `float` / `int64` / `double` 再试。

### 存档修改（需要导入存档）

流程：

1. 选存档目录（`...\Steam\CacheData\2_XXXXXX`）→【① 读取存档】生成 `*.cache.json`。
2. 在规则表填「查找内容（正则）/ 替换为」或点快捷按钮。
3. 【② 写入存档】回写 `.cache` → 游戏内【导入存档】。

## 存档修改示例

| 查找内容（正则） | 替换为 | 说明 |
|---|---|---|
| `\[1,10001,\d+\]` | `[1,10001,999999]` | 灵石改 999999 |
| `\[1,10002,\d+\]` | `[1,10002,999999]` | 宗门贡献改 999999 |
| `"gameLevel":\d+` | `"gameLevel":5` | 游戏难度改地狱 |

## 存档格式说明（社区整理）

- 文件头：校验串每个字符 XOR `0x03`，共 30 字节。
- 文件体：逐字节滚动异或 + gzip 压缩。
- 文件名：`@` 替换为 `/` 后 Base64 解码，再用 DES 解密得到内部名。

| 文件 | 内容 |
|---|---|
| `O33a@9fkh++YwffVNeV1RA==.cache` | DataUnit —— 人物数据（属性、背包、功法） |
| `eMZk7avfjaaSiFBwLwtZHg==.cache` | DataWorld —— 综合信息（难度、天气） |
| `1V5i793M2Ol7H@CBpcLu+A==.cache` | DataGrid —— 地图数据 |
| `soegnXJ65qU3ZS4O9xLDgg==.cache` | DataBuildSchool —— 宗门 |
| `W5hmZoonQsc=.cache` | DataMap —— 地图 |
| `CacheData` | 存档元信息 |

## 构建

无需安装 .NET SDK，用 Windows 自带的 .NET Framework 编译器：

```
build.bat
```

输出：`bin\GhbgEditor.exe`。
